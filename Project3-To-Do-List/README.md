# TaskFlow - Smart To-Do List:
TaskFlow is a modern and interactive To-Do List web application built using **HTML, CSS, and JavaScript**. It helps users organize daily tasks, track progress, manage deadlines, and improve productivity through a clean and responsive interface.

## Project Objective:
The goal of this project is to demonstrate JavaScript fundamentals and DOM manipulation concepts by creating a fully interactive web application.
The project focuses on:
* Event Handling
* DOM Manipulation
* State Management
* Dynamic Content Updates
* Local Storage
* Responsive Web Design

## Features:
* Add new tasks
* Mark tasks as completed
* Delete tasks
* Edit existing tasks
* Task completion statistics
* Progress percentage tracking
* Filter tasks (All / Completed / Pending)
* Due date support
* Clear all tasks option
* Dark Mode / Light Mode toggle
* Local Storage support (tasks remain saved after page refresh)
* Responsive design for mobile and desktop devices

## JavaScript Concepts Implemented:
### DOM Manipulation
* getElementById()
* querySelectorAll()
* createElement()
* innerHTML
* textContent
### Event Handling
* click events
* keypress events
* addEventListener()
### Arrays & Objects
* push()
* filter()
* forEach()
* splice()
### Local Storage
* localStorage.setItem()
* localStorage.getItem()
### Dynamic Styling
* classList.add()
* classList.remove()
* classList.toggle()

## Functionalities:
### Add Task
Users can add a new task with an optional due date.
### Edit Task
Users can update task names anytime.
### Complete Task
Completed tasks are visually distinguished using a strike-through effect.
### Filter Tasks
Users can view:
* All Tasks
* Completed Tasks
* Pending Tasks
### Progress Tracking
The application automatically calculates:
* Total Tasks
* Completed Tasks
* Pending Tasks
* Completion Percentage
### Theme Toggle
Users can switch between Light Mode and Dark Mode. The selected theme is stored in Local Storage.

## Local Storage Support:
TaskFlow stores:
* Task List
* Completion Status
* Due Dates
* Theme Preference
This ensures that user data remains available even after refreshing or reopening the browser.
