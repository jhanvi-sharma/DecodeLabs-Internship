# Student Registration Form:

## Project Overview:
Student Registration Form is a responsive web application built using HTML, CSS, and JavaScript. The project demonstrates form creation, client-side validation, password strength checking, dark mode functionality, and responsive design principles.
This project was developed as part of Project 4: Form Design & Validation.

## Features:
* Student Registration Form
* Full Name Validation
* Email Validation using Regular Expressions
* Phone Number Validation
* Age Validation
* Gender Selection using Radio Buttons
* Course Selection using Dropdown Menu
* Password Strength Indicator
* Show/Hide Password Feature
* Confirm Password Validation
* Success and Error Messages
* Dynamic Input Border Validation
* Dark Mode Toggle
* Theme Persistence using Local Storage
* Responsive Design for Mobile Devices

## Tech Stack:
* HTML5
* CSS3
* JavaScript (ES6)

## Validation Rules:
### Full Name
* Only alphabets and spaces allowed
### Email
* Must follow valid email format
### Phone Number
* Must contain exactly 10 digits
### Age
* Must be between 16 and 30 years
### Gender
* Selection is mandatory
### Course
* Selection is mandatory
### Password
Must contain:
* At least 8 characters
* One uppercase letter
* One lowercase letter
* One number
* One special character
### Confirm Password
* Must match the entered password
